Code Geass: Black Requiem — Russian Localization

Русификатор для Hearts of Iron IV

Версия русификатора: 1.0
Совместимость: Hearts of Iron IV 1.19.x
Оригинальный мод: Code Geass: Black Requiem — Russia in Chaos

Описание

Русская локализация глобальной модификации Code Geass: Black Requiem для Hearts of Iron IV, основанной на вселенной аниме Code Geass.

Русификатор адаптирует игровые тексты для русскоязычных игроков, сохраняя оригинальные механики, сюжет и атмосферу модификации.

Особенности русификатора

Перевод игрового текста, национальных фокусов, событий и решений.

Русификация названий государств и сценариев.

Перевод имён глав государств, генералов, адмиралов и политических советников.

Перевод названий коллективных руководств, регентских советов и британских зон.

Исправление отображения кириллицы на политической карте.

Совместимость с оригинальным Code Geass: Black Requiem.

Инструкция по установке

Для работы русификатора обязательно требуется оригинальный Code Geass: Black Requiem.

Установите оригинальный мод.

Скачайте последнюю версию русификатора из раздела Releases.

Откройте папку:

Документы\Paradox Interactive\Hearts of Iron IV\mod

Распакуйте туда архив русификатора. В папке mod должны находиться папка Code Geass Black Requiem RU и файл Code Geass Black Requiem RU.mod.

Проверьте, чтобы файл .mod ссылался на правильную папку русификатора.

Запустите Paradox Launcher.

Добавьте в игровой набор оригинальный Code Geass: Black Requiem и Code Geass Black Requiem RU.

Выберите русский язык игры и запустите Hearts of Iron IV.

Важно: оригинальный мод должен оставаться установленным. Русификатор не является самостоятельной модификацией.

Для корректного отображения переведённых имён лидеров рекомендуется начинать новую игру.
